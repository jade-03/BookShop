# 📚 Bookshop

**Bookshop** est une plateforme web permettant aux utilisateurs **d'acheter et de vendre des livres d'occasion en ligne**.

L'application permet de gérer les utilisateurs, les annonces et les échanges autour des livres.

## 🛠️ Technologies

* **Backend :** Symfony 8 / PHP
* **Frontend :** Angular / TypeScript
* **Base de données :** MySQL
* **Authentification :** JWT
* **API externe :** Google Books
* **Paiement :** Stripe *(à intégrer)*

## ✨ Fonctionnalités

* 👤 Inscription et authentification avec JWT
* 📖 Création et gestion d'annonces
* 🔎 Recherche et consultation de livres
* 📚 Récupération des informations via Google Books API
* 🛒 Gestion des achats
* 💬 Communication entre utilisateurs *(en cours de développement)*

## 🚀 Installation

### Backend

```bash
cd backend
composer install
symfony server:start
```

### Frontend

```bash
cd frontend
npm install
ng serve
```

L'application Angular est accessible sur `[BookShop](https://bookshop-cer0.onrender.com

)`.
